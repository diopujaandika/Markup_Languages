Elemen Preformatted Text | <pre>

Pengertian

Preformatted Text (<pre>) adalah elemen HTML yang digunakan untuk membuat konten halaman web persis dengan apa yang kita tulis pada text editor.

Kegunaan

  1. Digunakan untuk membuat konten sama persis dengan yang kita tulis di teks editor.
  2. Dapat meminimalisir penggunaan tag elemen lainnya.
  3. Dapat digunakan untuk membuat contoh baris code atau puisi.

Sintak


                    <pre>
                        Isi Konten
                            Isi Konten
                                Isi Konten
                    </pre>
  • Terdiri dari tag pembuka <> dan tag penutup </>.
  • Menggunakan kata pre untuk mendeklarasikan preformatted test.
  • Elemen ini bertipe block sehingga elemen setelahnya akan berada dibawah elemen ini.

Contoh

Contoh 1 | Code


                    body {
                    color: red;
                    }
