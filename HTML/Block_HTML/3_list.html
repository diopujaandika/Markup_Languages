Elemen <li>

Elemen <li> (tag list) adalah elemen HTML yang digunakan untuk membuat sebuah list pada halaman web.

Elemen <li> ini terdiri dari 3 macam list:

  1. Ordered List <ol>, digunakan untuk membuat list terurut berbentuk angka.
  2. Unodered List <ul>, digunakan untuk membuat list tak terurut berbentuk bulletin.
  3. Definition List <dl>, digunakan untuk membuat list yang dilengkapi dengan deskripsi atau definisi didalamnya.

Sintak Ordered List dan Unodered List

<ol atau ul> <li> Isi Konten </li>, </ol atau /ul>

Sintak Definition List

<dl> <dt> Judul list <dd> Isi Konten </dd>, </dt>, </dl>

Untuk membuat sebuah list kita harus menentukan terlebih dahulu jenis list apa yang sebaiknya kita gunakan sesuai dengan kasus dan kebutuhan kita, entah itu <ol> atau <ul>.

Selayaknya pada pembuatan elemen lainnya, membuat sebuah list diawali dengan sebuah tag pembuka <ol, ul, dan dl> dan diakhiri dengan sebuah tag penutup </ol, /ul, /dl>

Kemudian didalam <ol atau ul> kita bisa menambahkan sebuah list yang dideklarasikan dengan elemen list yaitu <li> yang diawali dengan tag pembuka <li> dan diakhiri dengan tag pembuka </li>. Di dalam tag list inilah kita dapat memberikan sebuah isi konten.

Khusus untuk <dl> kita tidak menggunakan <li>, tetapi menggunakan <dt> (data term) yang merupakan judul list dan didalamnya kita bisa menuliskan sebuah deskripsi isi list dengan memanfaatkan elemen <dd> (definition description) yang bisa kita sisipkan isi konten.

Contoh

Ordered List

  1. Langkah pertama
  2. Langkah kedua
  3. Langkah ketiga
  4. Langkah selanjutnya

Unodered List

  • List 1
  • List 2
  • List 3

Definition List

List 1
Ini adalah deskripsi list 1
List 2
Ini adalah deskripsi list 2
List 3
Ini adalah deskripsi list 3
