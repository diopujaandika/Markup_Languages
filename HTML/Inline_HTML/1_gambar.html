Elemen <img>

Elemen <img> (tag image) digunakan untuk membuat atau menampilkan sebuah gambar pada halaman web.

Elemen <img> ini dapat mengunkan relatif url dan absolute url

Sintak

<img src="lokasi " alt="nama image">

Elemen <img> hanya terdiri dari tag pembuka <>, tanpa ditutup dengan tag penutup

Elemen <img> bertipe inline, sehingga secara otomatis elemen ini tidak akan menambahkan garis baru ketika elemen berikutnya bertipe inline juga.

Elemen <img> memiliki 2 atribut yaitu src digunakan untuk memberikan alamat gambar diambil atau disimpan dan alt digunakan untuk memberikan nama gambar jika gambar gagal ditampilkan.

Ada 2 cara menampilkan gambar yaitu:

Relative URL

Relative url berarti gambar berasal dari local storage.

Absolute URL

Absolute url berarti gambar berasal dari internet storage.
