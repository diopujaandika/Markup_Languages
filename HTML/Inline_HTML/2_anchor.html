Elemen Anchor | <a>

Pengertian

Elemen anchor (<a>) adalah elemen HTML yang digunakan untuk membuat sebuah hyperlink ke halaman atau website lain, file, alamat email, atau URL lainnya.

Kegunaan

  • Membuat halaman web kita tertaut ke halaman atau website lain, file, alamat email, atau URL lainnya.
  • Dapat digunakan sebagai interaktivitas dalam membuat navigasi halaman web.

Sintak

<a href="alamat yang dituju"> Nama Tujuan </a>

Keterangan

  1. Terdiri dari tag pembuka <> dan tag penutup </>.
  2. Menggunakan huruf a untuk mendeklarasikan anchor.
  3. Elemen ini bertipe inline sehingga elemen setelahnya akan berada samping elemen ini, kecuali elemen-elemen yang bersifat block.
  4. Terdapat 2 atribut yang umum digunakan yaitu:
    • href="..." digunakan mentapkan sebuah target yang dituju.
    • target="..." digunakan untuk bagaimana alamat target yang dituju mau ditampilkan.

Contoh

<a href="https://..." target="_blank">Website</a>

Website

<a href="mailto:info@example.com">Email</a>

Email

<a href="tel:+6281271028744">Telepon</a>

Telepon

<a href="#address">Alamat>/a>

Alamat
