HTML | Hypertext Markup Language

Pengertian

HTML adalah salah satu bahasa markup yang khusus digunakan untuk menyusun struktur dasar halaman website.

Kegunaan

  1. Membangun struktur dasar halaman web yang disusun dari elemen-elemen HTML.
  2. Menghubungkan halaman web dengan berkas lainnya, seperti CSS dan JS.

Sintak

<Tag Pembuka> Isi Konten </Tag Penutup>

Keterangan

  • Elemen HTML umumnya diawali dengan yang namanya tag pembuka <> dan diakhiri dengan sebuah tag penutup </>.
  • Biasanya setiap elemen HTML memiliki satu atau lebih atribute di dalamnya.

Contoh

<a href="https://..." target="_blank">Website</a>
